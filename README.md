# 🎮 When Was the Golden Era of Video Games?

![Video Game](video_game.jpg)

Video games are big business — the global gaming market is projected to be worth more than **$300 billion by 2027**, according to *Mordor Intelligence*. With that much money at stake, major publishers are constantly racing to create the next big hit.

That raises an interesting question: **are video games actually getting better, or is the golden age of gaming already behind us?**

This project uses SQL (and a Python/pandas equivalent) to dig into critic and user review scores, alongside sales data, to find out which years gaming fans and critics loved most — and whether love translated into sales.

---

## 📊 Objective

- **Analyze** scores and sales for a sample of top-selling video games released since 1977.
- **Identify** the years critics and users rated highest.
- **Compare** critic opinion against user opinion, year by year.
- **Surface** candidate "golden years" of the video game industry.

---

## 🗃️ Dataset Overview

> ⚠️ **Note on the data:** The CSVs in `data/` are **synthetic/dummy data**, generated by `generate_dummy_data.py` for demonstration purposes — they are not the real Kaggle dataset. Game names, publishers, and scores are randomly generated and don't correspond to real titles. The generator is seeded, so re-running it produces the same data, and it's structured to loosely follow the shape of the real dataset (a small cluster of standout years, a long tail of average ones) so the queries below return a realistic, non-trivial result.
>
> If you want to run this against real data instead, swap the CSVs for the actual dataset on [Kaggle](https://www.kaggle.com/datasets/rush4ratio/video-game-sales-with-ratings) — the schema is designed to match.

### `game_sales.csv`
| Column     | Definition                       | Type      |
|------------|-----------------------------------|-----------|
| name       | Name of the video game            | `varchar` |
| platform   | Gaming platform                   | `varchar` |
| publisher  | Game publisher                    | `varchar` |
| developer  | Game developer                    | `varchar` |
| games_sold | Number of copies sold (millions)  | `float`   |
| year       | Release year                      | `int`     |

### `reviews.csv`
| Column       | Definition                 | Type      |
|--------------|-----------------------------|-----------|
| name         | Name of the video game      | `varchar` |
| critic_score | Critic score (0-10)         | `float`   |
| user_score   | User score (0-10)           | `float`   |

### `users_avg_year_rating.csv` *(derived)*
| Column          | Definition                          | Type    |
|-----------------|--------------------------------------|---------|
| year            | Release year                         | `int`   |
| num_games       | Number of games released that year   | `int`   |
| avg_user_score  | Average user score that year         | `float` |

### `critics_avg_year_rating.csv` *(derived)*
| Column            | Definition                          | Type    |
|-------------------|--------------------------------------|---------|
| year              | Release year                         | `int`   |
| num_games         | Number of games released that year   | `int`   |
| avg_critic_score  | Average critic score that year       | `float` |

The two derived tables are just `game_sales` joined with `reviews`, grouped by year — `generate_dummy_data.py` computes them the same way the SQL queries below do, so everything stays consistent.

## 🧠 Queries & Analysis

### 🔝 Best-selling games

```sql
SELECT *
FROM game_sales
ORDER BY games_sold DESC
LIMIT 10;
```

### 🏆 Critics' top ten years

```sql
SELECT
  g.year,
  COUNT(g.name) AS num_games,
  ROUND(AVG(r.critic_score), 2) AS avg_critic_score
FROM
  game_sales g
INNER JOIN
  reviews r ON g.name = r.name
GROUP BY
  g.year
HAVING
  COUNT(g.name) >= 4
ORDER BY
  avg_critic_score DESC
LIMIT 10;
```

### ✨ Golden years of gaming

```sql
SELECT
  u.year,
  u.num_games,
  c.avg_critic_score,
  u.avg_user_score,
  c.avg_critic_score - u.avg_user_score AS diff
FROM
  critics_avg_year_rating c
INNER JOIN
  users_avg_year_rating u ON c.year = u.year
WHERE
  c.avg_critic_score > 9 OR u.avg_user_score > 9
ORDER BY
  c.year ASC;
```

Prefer pandas over SQL? Each of these has a direct equivalent in `analysis.py` if you'd rather run it locally without a database.

## 📌 Conclusion

Once aggregated, the data highlights a handful of standout years where critics and users rated games unusually highly — the closest thing to a "golden era" signal in this sample. Looking at both **sentiment** (scores) and **sales** side by side gives a fuller picture of a game's success: critical acclaim and commercial performance don't always move together.
